🤖 AI AGENT - ИНСТРУКЦИЯ ПО ЗАПУСКУ НА WINDOWS
==================================================

📋 ЧТО НУЖНО СДЕЛАТЬ:

1. ПЕРВЫЙ ЗАПУСК:
   ✅ Дважды кликните на файл "setup.bat"
   ✅ Дождитесь завершения установки
   ✅ Дважды кликните на файл "start.bat"
   ✅ Приложение откроется в браузере!

2. КАЖДЫЙ ДЕНЬ:
   ✅ Просто кликните на "start.bat" - и всё!

🔧 ФАЙЛЫ ДЛЯ ЗАПУСКА:

setup.bat  - Настройка (запустить ОДИН РАЗ)
start.bat  - Запуск приложения (каждый день)
build.bat  - Сборка для продакшена
serve.bat  - Запуск собранной версии

📍 АДРЕС ПРИЛОЖЕНИЯ:
http://localhost:5173

🆘 ЕСЛИ НЕ РАБОТАЕТ:

1. Установите Node.js с сайта: https://nodejs.org/
2. Запустите setup.bat от имени администратора
3. Проверьте подключение к интернету
4. Убедитесь, что все .bat файлы в одной папке с проектом
