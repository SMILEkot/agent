# 🚀 AI Agent Desktop - Веб-совместимая версия

## 🎯 **Что это?**

Полнофункциональное AI Agent Desktop приложение с Warp-подобным терминалом, адаптированное для работы в веб-браузере без проблемных нативных зависимостей.

## ✨ **Основные возможности:**

### 🤖 **AI Agent Chat**
- Интеграция с OpenAI, Ollama, и другими провайдерами
- Автоопределение доступных AI сервисов
- Умный fallback на базовый ассистент
- Markdown поддержка с подсветкой кода

### 🚀 **Warp-подобный AI Terminal**
- **Agent Mode** (Ctrl+I) - команды естественным языком
- **AI Command Suggestions** (#описание) - умные подсказки команд
- **Современный интерфейс** с блоками команд и историей
- **Автоисправление ошибок** - AI пытается исправить неудачные команды
- **Симуляция команд** - работает без реального терминала

### 🌐 **Веб-совместимость**
- Убраны проблемные нативные зависимости (`node-pty`)
- Обновлены xterm пакеты до новых версий
- Симуляция популярных команд терминала
- Кроссплатформенная поддержка через User-Agent

## 🛠️ **Быстрый старт:**

### 1. **Исправление зависимостей:**
```bash
# Запустите скрипт исправления зависимостей
fix-deps.bat

# Или вручную:
npm cache clean --force
rm -rf node_modules package-lock.json
npm install --no-optional
```

### 2. **Запуск приложения:**
```bash
# Быстрый запуск
start.bat

# Или вручную:
npm run dev
```

## 📦 **Изменения в зависимостях:**

### ✅ **Добавлено:**
- `@xterm/xterm` - современная версия xterm
- `@xterm/addon-fit` - адаптер размера
- `@xterm/addon-web-links` - поддержка ссылок
- `@xterm/addon-search` - поиск в терминале

### ❌ **Удалено:**
- `node-pty` - требовал Visual Studio Build Tools
- `xterm` (старая версия)
- `xterm-addon-*` (устаревшие пакеты)

## 🎮 **Как использовать AI Terminal:**

### **Agent Mode (Ctrl+I):**
```
"покажи все файлы в папке"
"установи Node.js последней версии"
"найди все процессы с именем node"
"проверь статус git репозитория"
```

### **Command Suggestions (#):**
```
#показать процессы → ps aux / tasklist
#проверить память → free -h / systeminfo
#git статус → git status
#ping google → ping google.com
```

## 🔧 **Поддерживаемые команды:**

### **Навигация:**
- `ls`, `dir` - список файлов
- `pwd` - текущая папка
- `cd <path>` - смена папки

### **Система:**
- `ps aux`, `tasklist` - процессы
- `whoami` - текущий пользователь
- `date` - текущая дата

### **Разработка:**
- `node -v` - версия Node.js
- `npm -v` - версия npm
- `git status` - статус git

### **Сеть:**
- `ping <host>` - проверка связи

### **Утилиты:**
- `echo <text>` - вывод текста
- `clear`, `cls` - очистка экрана

## 🌍 **Кроссплатформенность:**

Приложение автоматически определяет платформу через `navigator.userAgent` и адаптирует команды:

- **Windows**: `dir`, `tasklist`, `systeminfo`
- **Linux/Mac**: `ls`, `ps aux`, `free -h`

## 🔄 **Fallback механизмы:**

1. **AI недоступен** → Базовый ассистент
2. **Команда не найдена** → Подсказки и альтернативы
3. **Ошибка выполнения** → AI пытается исправить
4. **Нет интернета** → Локальная симуляция

## 🐛 **Решение проблем:**

### **Ошибка установки зависимостей:**
```bash
# Очистите кэш и переустановите
npm cache clean --force
rm -rf node_modules package-lock.json
npm install --no-optional --legacy-peer-deps
```

### **Приложение не запускается:**
```bash
# Проверьте версии
node --version  # должно быть >= 16
npm --version   # должно быть >= 8

# Переустановите зависимости
fix-deps.bat
```

### **AI не работает:**
- Проверьте настройки AI провайдеров
- Убедитесь в наличии интернета
- Используйте базовый ассистент как fallback
