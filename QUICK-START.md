# 🚀 БЫСТРЫЙ СТАРТ - AI Agent Desktop (Веб-версия)

## ❌ **ПРОБЛЕМА РЕШЕНА!**

Больше **НЕ НУЖНЫ Visual Studio Build Tools**! Создана полностью веб-совместимая версия.

## ⚡ **БЫСТРЫЙ ЗАПУСК (2 команды):**

### 1. **Настройка веб-версии:**
```bash
setup-web.bat
```

### 2. **Запуск приложения:**
```bash
start-web.bat
```

## 🎯 **Что работает:**

### 🤖 **AI Agent Chat:**
- ✅ Интеграция с OpenAI, Ollama
- ✅ Автоопределение AI сервисов
- ✅ Fallback на базовый ассистент

### 🚀 **Web Terminal (НОВЫЙ!):**
- ✅ **Agent Mode** (Ctrl+I) - команды естественным языком
- ✅ **Симуляция команд**: ls, pwd, cd, ps, node -v, git status, ping
- ✅ **Современный интерфейс** с блоками команд
- ✅ **Копирование и повтор** команд
- ✅ **Кроссплатформенность** - Windows и Linux команды

### 📁 **File Manager:**
- ✅ Просмотр файлов и папок
- ✅ Навигация по проекту

## 🎮 **Как использовать Web Terminal:**

### **Обычные команды:**
```bash
ls          # список файлов
pwd         # текущая папка
cd ..       # перейти назад
ps aux      # процессы
node -v     # версия Node.js
git status  # статус git
ping google.com  # проверка сети
help        # список команд
```

### **Agent Mode (Ctrl+I):**
```
"покажи все файлы в папке"
"проверь версию Node.js"
"найди все процессы"
"очисти экран"
```

## 🔧 **Что изменилось:**

### ❌ **Убрано:**
- `node-pty` - требовал Visual Studio Build Tools
- `xterm` (старая версия)
- Все нативные зависимости

### ✅ **Добавлено:**
- `@xterm/xterm` - новая версия
- `@xterm/addon-*` - современные аддоны
- Веб-совместимая симуляция команд
- SimpleWebTerminal компонент

## 📋 **Новые файлы:**

- **setup-web.bat** - настройка веб-версии
- **start-web.bat** - запуск веб-версии
- **package-web.json** - веб-совместимые зависимости
- **SimpleWebTerminal.tsx** - веб-терминал
- **SimpleWebTerminalPage.tsx** - страница терминала

## 🌐 **Доступ к приложению:**

После запуска `start-web.bat` приложение откроется на:
**http://localhost:5173**
