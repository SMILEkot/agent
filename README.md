# 🚀 AI Agent Desktop

Простое десктопное приложение с AI агентом и терминалом.

## ⚡ Запуск (1 команда!)

```bash
start.bat
```

**Все! Приложение откроется в отдельном окне.** 🖥️

## ✨ Что умеет

### 🤖 AI Chat
- Общение с искусственным интеллектом
- Помощь с кодом и вопросами

### 💻 Умный Terminal
- **Agent Mode** - нажмите **Ctrl+I** и пишите команды обычными словами
- Обычные команды: `ls`, `pwd`, `cd`, `node -v`, `help`

### 📁 File Manager
- Просмотр файлов проекта
- Навигация по папкам

## 🎮 Примеры

**Обычные команды в Terminal:**
```bash
ls          # список файлов
pwd         # где я нахожусь
node -v     # версия Node.js
help        # все команды
```

**Agent Mode (Ctrl+I):**
```
"покажи файлы"
"проверь версию Node"
"очисти экран"
```

## 🔧 Если что-то не работает

### 🚨 Ошибка "Cannot find module @rollup/rollup-win32-x64-msvc"?

**Это известная проблема npm! Решение:**

```bash
fix-deps.bat
```

Затем:
```bash
start.bat
```

### 🚨 Ошибка "dependencies could not be resolved"?

```bash
fix-deps.bat
```

Затем снова:
```bash
start.bat
```

### 💡 Другие проблемы:
1. Установите [Node.js](https://nodejs.org) (последнюю версию)
2. Запустите `start.bat` как администратор
3. Подождите - первый запуск может занять время
4. Перезагрузите компьютер если ничего не помогает
